这两天主要完成了一个原始静态页面的功能实现，没有使用框架（如 Vue / ElementUI），全部基于原生 JS（window + DOM 操作）实现。

在此过程中，完成了前后端交互的打通，包括接口调用、数据提交以及页面渲染，形成了一个基础的业务闭环。

后端方面复用了之前封装的通用能力（统一返回结果、全局异常处理），并采用 DTO 进行数据传输，简化了不必要的 VO 设计，优先保证开发效率。

整体属于基础功能开发，但相比简单页面搭建，已经具备了完整请求链路（前端 → 接口 → 后端 → 数据返回）的实现能力。
