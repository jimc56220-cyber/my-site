# 2026-03-29：简单学习 Nacos、Feign 和 Gateway

## 为什么要从单体走向微服务

单体式架构代码耦合度高，后期不便于升级和维护。微服务可以看作是分布式架构的一种更规范、更强调边界的实现方式。

## 微服务拆分后，服务之间怎么互相调用

最简单的方式是用 RestTemplate 发送远程调用请求。更方便的方式是引入 Nacos 做服务注册与发现，再配合 Feign 简化远程调用代码。

这次也简单接触了几个概念：

- 服务注册与发现
- 临时实例
- 集群优先
- 命名空间
- 远程调用

## Feign

简单来说，Feign 可以把请求地址和请求方法封装成接口调用的形式，让远程调用看起来更像本地方法调用。

## Gateway

Gateway 是网关。我的初步理解是，它有点像 Nginx 反向代理：统一接收请求，再根据规则转发到不同服务，也可以处理跨域、鉴权等公共问题。

## 感受

这次学习内容不算少，但整体还是有些迷糊。微服务相关概念很多，我现在还不能说理解得很深，不过已经大概知道 Nacos、Feign、Gateway 分别解决什么问题，以及为什么项目变复杂后需要它们。
