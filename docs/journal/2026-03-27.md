service

```
@Slf4j
@Service
@RequiredArgsConstructor
public class MailServiceImpl implements MailService {

    private final JavaMailSender mailSender;

    @Value("${spring.mail.username}")
    private String from;

    // 你自己接收通知的邮箱
    private final String to = "2859846941@qq.com";
    @Override
    public void sendAppointmentNotice(Message message) {
        try {
            log.info("开始发送邮件，预约人邮箱={}, 预约时间={}", message.getContactEmail(), message.getAppointmentTime());

            MimeMessage mimeMessage = mailSender.createMimeMessage();
            MimeMessageHelper helper = new MimeMessageHelper(mimeMessage, true, "UTF-8");

            helper.setFrom(from);
            helper.setTo(to);
            helper.setSubject("收到新的预约通知");

            String content = """
                    收到新的预约信息：

                    姓名：%s
                    邮箱：%s
                    类型：%s
                    留言内容：%s
                    预约时间：%s
                    创建时间：%s
                    """.formatted(
                    message.getVisitorName(),
                    message.getContactEmail(),
                    message.getInterestType(),
                    message.getMessageContent(),
                    message.getAppointmentTime(),
                    message.getCreateTime()
            );

            helper.setText(content, false);

            mailSender.send(mimeMessage);
        } catch (MessagingException e) {
            throw new RuntimeException("邮件发送失败",e);
        }
    }
}
```

然后去调用就行



### 2 遇到的问题

发送邮件很慢，因为我把发送邮件写在了addMessage里，所以客户端留言的时候，消息发送成功的很慢。所以要以异步操作。



异步操作我找到了两种方法。



第一种



new Thread(() -> {
    mailService.sendAppointmentNotice(message);
}).start();



每次请求都重新创建线程，还会让Spring的AOP失效，可以用@Async



第一步

@EnableAsync
@SpringBootApplication
public class YourApplication {
    public static void main(String[] args) {
        SpringApplication.run(YourApplication.class, args);
    }
}



然后

在邮件方法上加 `@Async`

```
    @Async
    @Override
    public void sendAppointmentNotice(Message message) {
```



然后调用就行



    // 异步发邮件
    mailService.sendAppointmentNotice(message);



然后留言就顺畅了，问题解决
